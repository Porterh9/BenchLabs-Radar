1. Device IP

On the radar, tap the gear icon → Change Parameters. It shows an IP address like 192.168.1.42 — enter it below. Make sure your phone is on the same WiFi network as the radar (not cellular data, not a different network).

3. OpenSky Account (optional)

Skip this and the radar keeps tracking at a basic refresh rate (updates every ~4 minutes). Add these for live updates every 15-30 seconds instead. Free, takes about 2 minutes:

  1. Go to opensky-network.org and log in, or register a free account if you don't have one yet.
  2. Once logged in, find your Account page (top menu) and look for the API Client section.
  3. Create a new API client and copy the Client ID and Client Secret it gives you.
  4. Paste them below.

OpenSky restructured their site in 2026 — if a step above doesn't match what you see, their Account page is the one to look for; the API Client option lives there.
